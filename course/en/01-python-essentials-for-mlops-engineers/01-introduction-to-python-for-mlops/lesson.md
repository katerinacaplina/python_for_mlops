# Lesson

In many infrastructure and platform roles, Python appears as a support tool long before it becomes a primary language. It is often used for automation, small utilities, configuration handling, internal scripts, or CI-related tasks.

This module is not meant to teach all of Python. Its goal is narrower and more practical: to give you enough confidence to read, run, and structure simple Python code before moving into the rest of the course.

By the end of this lesson, you should be able to read simple Python code, write small functions, split logic into modules, load configuration from files, run a basic script locally, and understand the purpose of a virtual environment.
