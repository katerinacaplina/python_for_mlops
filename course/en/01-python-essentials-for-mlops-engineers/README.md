# Module 1. Python essentials for MLOps engineers

[Русская версия](../../ru/01-python-essentials-for-mlops-engineers/README.md)

This preparation module is designed for engineers coming from DevOps, SRE, platform engineering, or infrastructure roles who want a smoother transition into Python for MLOps.

It covers the minimum Python foundation needed for the rest of the course: functions, modules, imports, files, JSON and YAML, virtual environments, and a light introduction to testing.
