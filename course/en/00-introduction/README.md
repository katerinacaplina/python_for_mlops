# Introduction

[Русская версия](../../ru/00-introduction/README.md)

This section explains what the course is about, who it is for, and how to navigate the repository.

The course is designed to help engineers move from rough ML-oriented Python code to more structured, testable, and maintainable components that can be used in real systems.

If you are comfortable with basic Python, you can move through the main track as modules are published. If Python still feels unfamiliar, start with the preparation module first.
