# Модуль 1. Python essentials for MLOps engineers

[English version](../../en/01-python-essentials-for-mlops-engineers/README.md)

Этот подготовительный модуль предназначен для инженеров из DevOps, SRE, platform engineering и инфраструктурных ролей, которым нужен более мягкий вход в Python для MLOps.

Здесь разбирается минимальная база Python, которая понадобится дальше в курсе: функции, модули, импорты, работа с файлами, JSON и YAML, виртуальные окружения и лёгкое введение в тестирование.
