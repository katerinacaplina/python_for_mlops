# Введение

[English version](../../en/00-introduction/README.md)

Этот раздел объясняет, о чём курс, для кого он предназначен и как устроен репозиторий.

Курс помогает перейти от сырого ML-ориентированного Python-кода к более структурированным, тестируемым и поддерживаемым компонентам, которые можно использовать в реальных системах.

Если вы уверенно владеете базовым Python, можно двигаться по основному треку по мере публикации модулей. Если Python пока даётся неуверенно, лучше сначала пройти подготовительный модуль.
